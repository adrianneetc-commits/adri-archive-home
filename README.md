 # Glassmorphic Static Site

A responsive, multi-page web layout featuring a modern glassmorphic frosted-glass aesthetic built with semantic HTML5 and vanilla CSS.

## Pages
* `index.html` - Hub / Landing page
* `about.html` - Project and team overview
* `services.html` - Services and offerings
* `contact.html` - Contact details and inquiry routing

## Deployment
To deploy via **GitHub Pages**:
1. Navigate to **Settings** > **Pages** in your repository.
2. Select **Deploy from a branch** under *Build and deployment*.
3. Choose `main` branch and `/ (root)` folder, then click **Save**.
